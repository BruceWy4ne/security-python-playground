# PostgreSQL Security Lab

A hands-on PostgreSQL lab built to practice database fundamentals and connect Python with PostgreSQL for basic security-oriented data analysis.

## Overview

This project was created while learning SQL, PostgreSQL, and Python database integration.

The lab uses a simple user and login-attempt database to practice querying authentication-related data and identifying potentially suspicious login behavior.
